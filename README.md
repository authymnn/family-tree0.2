# สาแหรกตระกูล — แอพบันทึกผังครอบครัว (Thai Family Tree + Supabase)

เว็บแอพพลิเคชันสำหรับสร้างและจัดการผังตระกูลขนาดใหญ่ รองรับการแก้ไขร่วมกันทั้งครอบครัวแบบเรียลไทม์ผ่าน **Supabase** พร้อมระบบ **แอดมินล็อก/ปลดล็อกสิทธิ์การดูและแก้ไข**

## ความสามารถหลัก
- **ผังตระกูลแบบอินเทอร์แอกทีฟ**: Pan/Zoom, โหมดกะทัดรัด, พับ/กางกิ่งย่อย, กรองตามสายตระกูล, ไฮไลต์สายตรง, และโฟกัสเริ่มจากคนใดก็ได้
- **รูปภาพ & อัลบั้มความทรงจำ**: อัปโหลดรูปโปรไฟล์และอัลบั้มภาพหลายรูป (เก็บบน Supabase Storage อัตโนมัติเมื่อเชื่อมต่อ)
- **ตกแต่งธีมสี & พื้นหลัง**: 5 ธีมสี (รวม Dark Mode) ปรับสีหลัก/สีรองเองได้ เลือกพื้นหลัง ต้นไม้ใหญ่ / บ้านอบอุ่น / สีน้ำ / ลายจุด / รูปภาพเอง พร้อมปรับความเบลอและความเข้ม
- **โหมดดูง่าย (Elder-Friendly)**: ตัวอักษรใหญ่ อ่านสบายตา ไม่ต้องกลัวกดแก้พลาด
- **หมายเหตุประจำตัว (Notes)** และ **คำนวณลำดับญาติภาษาไทย**
- **ระบบแอดมินล็อก/ปลดล็อก + ซิงก์เรียลไทม์ผ่าน Supabase**:
  - ล็อก/ปลดล็อกการเข้าชม (เปิดทุกคนดูได้ / ล็อกด้วยรหัสเข้าบ้าน)
  - ล็อก/ปลดล็อกการแก้ไข (เปิดทุกคนแก้ได้ / ต้องใส่รหัสแก้ไข / ล็อกให้เฉพาะแอดมิน)

---

## วิธีเชื่อมต่อ Supabase (ฟรี 100%)

1. สมัครและสร้างโปรเจกต์ใหม่ที่ [supabase.com](https://supabase.com)
2. เข้าเมนู **SQL Editor** → เปิดไฟล์ `supabase/schema.sql` ในโปรเจกต์นี้ คัดลอกทั้งหมดไปวางแล้วกด **Run**
3. เข้าเมนู **Project Settings → API** คัดลอกค่า **Project URL** และ **anon public key**
4. สำหรับรันในเครื่อง: คัดลอก `.env.example` เป็น `.env` แล้ววางค่าทั้งสองลงไป
   ```env
   VITE_SUPABASE_URL=https://xxxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJhbGci...
   VITE_FAMILY_TREE_ID=main
   ```
5. รันคำสั่ง:
   ```bash
   npm install
   npm run dev
   ```

> **รหัสผ่านเริ่มต้น**: แอดมิน `1234` · รหัสเข้าบ้าน `0000` · รหัสแก้ไข `8888` (เปลี่ยนได้ทันทีในปุ่ม **"แอดมิน/สิทธิ์"** บนหน้าเว็บ)

## วิธี Deploy ขึ้น GitHub Pages (พร้อมใช้ฐานข้อมูล Supabase)

1. Push โค้ดนี้ขึ้น Repository บน GitHub (branch `main`)
2. ไปที่ **Settings → Secrets and variables → Actions → New repository secret** เพิ่ม 2 ค่า:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
   - *(ไม่บังคับ)* `VITE_FAMILY_TREE_ID` (ค่าเริ่มต้นคือ `main`)
3. ไปที่ **Settings → Pages** → ตรง **Source** เลือก **GitHub Actions**
4. ระบบจะ Build และ Deploy อัตโนมัติ พร้อมให้ทุกคนในครอบครัวเปิดลิงก์ใช้งานร่วมกันได้ทันที!
